SHIFA-BIRY FOUNDATION media for GitHub

Upload files inside Images/ to the Images folder in your repository. Upload files inside videos/ to the videos folder. Do not upload the outer ZIP file directly to GitHub.

The videos have neutral, organization-branded filenames because the exact activities in every clip have not been independently verified.

Two byte-identical duplicate video uploads were included only once to avoid repeated videos on the website. See file-name-guide.csv.
